# UPL-Uncertain-Programming-Language-
UPL (.uc) — a quirky interpreted language whose runtime speaks in the voice of the Department of Uncertainty: truth is Legit, lies are Fake, nothing is Nun. Dynamic typing, groups-with-methods, try/catch (goforit/nab/yeet), for/forevery, 60+ themed builtins, file I/O. Tree-walking interpreter, one main.cpp, zero deps, VS2022.
